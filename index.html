Try it on your Android phone

  1. Download CameraCoach-0.3.1.apk using the button above. GitHub's automatic source archives contain only this website and documentation, not an installable app.
  2. Open the APK. If prompted, allow your browser or file app to install unknown apps only if you trust this release. You can revoke that installation permission afterward.
  3. Open CameraCoach. Grant camera access for live coaching, or select Open photo to try the editor without camera permission.
  4. For online pose ideas, choose Pose guide → Find reference poses, review the background choice, and search. Inspect the photo and outline before applying it.

Do not disable Play Protect or other security protections if a download is blocked. Managed phones and regional developer-verification requirements may prevent installation.

Already using a development build?

The public APK uses a dedicated release signing key. It cannot replace an older debug-signed CameraCoach in place. Preserve your photos and any settings you need before deciding whether to uninstall the old debug app. We do not uninstall it for you.

How do updates work?

There is no automatic updater. Download later versions from the same GitHub repository. Public updates will reuse the release signing key and increase the version code, so they can install over this release. The APK checksum and public signing-certificate information are included with each release.

Which phones work?

Android 10 or newer is required. Physical-device testing so far is limited to a Samsung Galaxy S23 FE. Camera access, zoom, processing, and performance vary by phone. There is no iOS version yet.

Privacy information / September 25, 2026

Your pictures are not search requests.

This information covers CameraCoach Android v0.3.1 and this distribution website, maintained through the GitHub account ssanket23. It describes the current implementation, not a claim of regulatory certification.

Camera, photos, and local analysis

The camera is used for preview, local composition/pose analysis, and photographs you choose to capture. Frames and joint coordinates used for coaching are processed locally and are not uploaded by CameraCoach. The app does not identify people or infer gender. Style selection is yours.

Original captures and exported copies are saved in Pictures/CameraCoach. Selected photos are accessed through Android's photo picker; the app does not request broad photo-library, microphone, contacts, or location permission. No CameraCoach account is required.

Optional Wikimedia Commons search

Only tapping Search free photos starts a reference search. The chosen background keyword and fixed search filters go to Wikimedia Commons. Wikimedia receives ordinary network information such as IP address, request time, and user-agent, and hosts the downloaded images. No camera photo, location, or detected joints are sent by this search.

Reference analysis is local. Thumbnails are held temporarily in memory while the panel is used, not saved to your gallery. Selected normalized pose geometry and attribution can remain in temporary Android activity state. Source and license buttons open your browser; those sites have their own policies. See the Wikimedia privacy policy.

Google ML Kit diagnostics are separate

The bundled Google ML Kit SDK processes image inputs and inference outputs on-device. It separately sends SDK diagnostic and usage metrics to Google, including device/app information, per-installation identifiers, performance, configuration, events/errors, and input/output sizes. Pose detection also uses Firebase services for remote configuration diagnostics. These SDK connections can occur even when you do not search Commons.

Google describes HTTPS transmission and its own handling of this information in ML Kit Terms & Privacy, its Android data disclosures, and the Google privacy policy. CameraCoach has no in-app switch for disabling SDK metrics. No separate CameraCoach analytics backend or advertising SDK is configured.

Sharing and speech

Sharing happens only when you choose a receiving app through Android. The receiving app controls its handling of the photo. Optional spoken coaching uses a voice marked as offline by your installed text-to-speech provider; the provider and operating system are outside CameraCoach's control.

Retention and your choices

You can decline or revoke camera access, avoid online reference search, leave voice off, and refrain from sharing. Delete saved photos through your gallery or file manager. Clearing app storage removes local preferences/state but does not necessarily remove gallery images. Uninstalling stops further app activity, but does not erase data previously handled by third-party providers. Refer to their policies for retention and data requests.

This website and downloads

The site uses no added analytics scripts, external fonts, advertising, cookies, or local-storage tracking. GitHub hosts the site, repository, and download assets and receives request information under the GitHub privacy statement. Following external links subjects those requests to the destination's policies.

Public content and support

Commons results are not curated. Keyword/license filters and pose checks do not guarantee suitable content or rights for every use. The prototype is not specifically designed for children. Never imitate dangerous locations or movements.

For questions or corrections, use CameraCoach issues. Issues are public: do not include private photos or sensitive information. If your question needs personal details, first request a private contact channel without posting those details. Material changes will be documented with future releases.
